QuickEdit 打开速度对比

双击打开一个 10.8 万行的 Go 文件，而编辑器还没有打开任何窗口时：登录后就在后台待命的 QuickEdit 用 — 毫秒；别的编辑器要先冷启动，TextEdit —，Zed —，Sublime Text —，VS Code —。QuickEdit 自己冷启动是 — 毫秒，在冷启动里也最快。 编辑器已经开着时，Zed 把文件开成标签页最快， — 毫秒；QuickEdit 每个文件开一个新窗口， — 毫秒。

双击文件：编辑器没有打开的窗口

别的编辑器这时要冷启动。“QuickEdit 常驻”是登录时已在后台启动、没有窗口的 QuickEdit：这是它的默认设置，可以在应用菜单里关掉；别的编辑器默认不会这样做，不过也能手动加进登录项。“QuickEdit”是它没在运行时的冷启动。

为什么用 MyGo 五种 UI 框架写同一个最小编辑器

打开 big.go，到带语法高亮的内容出现的毫秒数，10 次的中位数。iced 和 egui 一次排版整个文件；GPUI 先显示白字，再在后台上色；原生 AppKit 版不做高亮，是速度下限。

测试方法
机器
Mac mini（Apple M2，16 GB），macOS 26，2026 年 11 月 8 日。
编辑器
QuickEdit 0.1.0（MyGo 0.8.3），TextEdit（系统自带），Sublime Text 4（build 4215），CotEditor 7.1.3，Zed 1.27.0，VS Code 1.145.2，Typora（本机已装）。
QuickEdit 常驻
以登录项的方式在后台启动（不开窗口），等 3 秒后再打开文件；每次测量前都重新启动一次。
怎么打开
用 NSWorkspace 让编辑器打开文件，和在 Finder 里双击走同一条路。冷启动前先退出编辑器，并删掉它保存的窗口状态。
怎么计时
窗口服务器里出现标题含文件名的窗口后，不断截取这个窗口，取最后一次有超过 1% 像素变化的时刻，此后 1.5 秒不再变化。光标闪烁和滚动条淡出变化太小，不计入；文字出现、语法高亮上色、Markdown 渲染都计入。
为了公平
测试期间关闭系统的窗口打开动画；每个编辑器都关掉恢复上次窗口的功能；VS Code 用临时数据目录启动，不装扩展；每个编辑器先启动一次不计时，排除系统第一次运行程序时的检查。
没有测的
滚动和输入的流畅度、搜索速度、插件生态。CotEditor 和 TextEdit 是原生 AppKit 应用，打开大文件时会在后台继续排版，这里只计到画面稳定为止。
